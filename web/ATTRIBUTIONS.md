# Artwork credits

Chess piece SVGs are generated by `python-chess` (`chess.svg.piece`) using the Cburnett piece design, the same set listed by Lichess as `public/piece/cburnett`.

The Lichess attribution and license listing is available in [Lichess COPYING.md](https://github.com/lichess-org/lila/blob/master/COPYING.md). The Cburnett piece design is credited to Colin M. L. Burnett.
